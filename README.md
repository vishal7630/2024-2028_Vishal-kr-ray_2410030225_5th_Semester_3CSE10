## 📌 About the Internship

The **SQL and Database Management Systems Virtual Internship** focused on developing practical and industry-relevant knowledge of database technologies.

The internship covered the complete database management lifecycle, starting from relational database design and advanced SQL querying to NoSQL data modelling, business intelligence, full-stack integration, performance optimization, security, backup and recovery, and scalability.

The internship followed a structured **week-wise curriculum** consisting of conceptual learning, hands-on laboratory activities, weekly assessments, project documentation, and a final assessment.

---

## 🎯 Objectives

- Understand core database concepts and DBMS fundamentals.
- Learn SQL and NoSQL database systems.
- Design relational databases using ER modelling and normalization.
- Write advanced SQL queries using joins, subqueries and aggregation.
- Learn MongoDB and document-based NoSQL databases.
- Perform data aggregation and ETL operations.
- Build interactive dashboards using Power BI and DAX.
- Integrate databases with Node.js and Express.
- Develop RESTful APIs using FastAPI and SQLAlchemy.
- Understand database indexing and query optimization.
- Learn database security and SQL injection prevention.
- Understand backup and recovery strategies.
- Study scalability techniques such as replication, sharding and clustering.

---

## 📅 Week-wise Curriculum

| Week | Module | Description |
|---|---|---|
| **1** | Database Foundations & Relational Design | Database concepts, SQL vs NoSQL, ER modelling, normalization, DDL and basic DML operations |
| **2** | Advanced SQL & NoSQL Fundamentals | Joins, subqueries, aggregation, GROUP BY/HAVING, MongoDB and CRUD operations |
| **3** | Data Aggregation, ETL & Power BI | ETL concepts, data transformation, Power BI, dashboards and visualizations |
| **4** | Data Modeling & Full-Stack Integration | Power BI relationships, DAX, Node.js, Express, PostgreSQL and CRUD APIs |
| **5** | Backend APIs & Data Integration | FastAPI, SQLAlchemy, RESTful CRUD APIs and external API integration |
| **6** | Database Performance, Security & Backup | Indexing, query optimization, roles and permissions, SQL injection prevention, backup and recovery |
| **7** | Scalability & High Availability | Replication, sharding, clustering and real-world database use cases |
| **8** | Advanced NoSQL & Capstone Project | MongoDB aggregation, advanced indexing, geospatial queries, time-series modelling and capstone project |
